# Assignments 29-30 (JSP)

Copy this folder into a servlet container such as Apache Tomcat as the web application root. Add the MySQL Connector/J JAR to `WEB-INF/lib`, update the credentials in `WEB-INF/jdbc.jspf`, and run the SQL in `schema.sql`.

Open `/assignment29/register.jsp` for the registration example and `/assignment30/employees.jsp` for the employee CRUD example.
