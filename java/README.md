# Java College Lab Assignments

This folder contains runnable examples based on the Java Lab Manual.

- `Assignment01` through `Assignment13` contain the exercises from the manual.
- Assignments 1–5 are the requested submission scope for GitHub.
- Assignment 12 includes examples of user-defined packages.

Compile from this folder with:

```text
javac Assignment01/*.java
java -cp Assignment01 EnvironmentAndMethods
```
